Static logo artwork: approved first-round shapes retained. The seven original files are byte-for-byte unchanged.
Open shoof-gaze-pointer.svg directly in a browser, or embed it as an object. JavaScript will not run in img mode.
For inline SVG: load shoof-gaze.js and call attachShoofGaze(svgElement). Keyboard arrows move the gaze. Enter/Space replay it.
shoof-gaze-animated.svg is a standalone one-shot SVG timeline, not pointer tracking. Use a static variant where reduced motion is required and the host cannot control SVG playback.
The cursor is a standalone vector for presentation. The QR is non-scannable. The food image is a raster concept, not a GLB or an interactive model.
shoof-table-card.svg is the editable face layout for the fictional venue, not a print-ready QR or 3D mockup. Physical sizes are recommended starting points and need a print proof.
